# Lovable AI Gateway Dependencies - Isolation Document

## Purpose
This document identifies all dependencies on Lovable infrastructure that must be removed in Phase 2.

---

## 1. AI Chat Feature (`/supabase/functions/chat/index.ts`)

### Current Implementation
```typescript
// Lines 17, 63-76
const LOVABLE_API_KEY = Deno.env.get("LOVABLE_API_KEY");

const response = await fetch("https://ai.gateway.lovable.dev/v1/chat/completions", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${LOVABLE_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "google/gemini-3-flash-preview",  // Lovable-specific model identifier
    messages: [...],
    stream: true,
  }),
});
```

### Issues
- ⚠️ **Hard dependency on `ai.gateway.lovable.dev`**
- ⚠️ **Requires `LOVABLE_API_KEY` environment variable**
- ⚠️ **Uses Lovable-specific model naming** (`google/gemini-3-flash-preview`)
- ⚠️ **Cannot migrate without replacing this endpoint**

### Phase 2 Migration Plan
Replace with **OpenAI API** (gpt-4-turbo-preview):
```typescript
const OPENAI_API_KEY = Deno.env.get("OPENAI_API_KEY");

const response = await fetch("https://api.openai.com/v1/chat/completions", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${OPENAI_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "gpt-4-turbo-preview",
    messages: [...],
    stream: true,
  }),
});
```

**Effort**: ~2-4 hours (straightforward API swap)

## Notes for Phase 2 Implementation

1. **OpenAI Model Recommendation**: Use `gpt-4-turbo-preview` for best balance of:
   - Cost (~$0.01/1K input tokens, $0.03/1K output tokens)
   - Speed (faster than GPT-4, almost as capable)
   - Context window (128K tokens)

2. **Alternative Providers** (for future):
   - Anthropic Claude 3 (better reasoning, larger context)
   - Google Gemini (multimodal, competitive pricing)
   - All require similar migration effort

3. **Cost Estimation**:
   - Average chat: 500 input + 500 output tokens
   - Cost per chat: ~$0.02
   - 100 chats/day = $2/day = $60/month
   - Budget: $50-200/month depending on usage

4. **Backward Compatibility**:
   - Frontend expects SSE format (data: {json}\n\n)
   - OpenAI uses identical format
   - No frontend changes required ✅
